Website Portfolio Project
2026 May | 2026 August
Project Overview
Over the summer, I decided to finally pursue a personal interest of mine; I have always wanted to create my own website, as I saw the project as an interesting challenge with relevant payoffs. Thus, I built this website to showcase my portfolio and my ability to take risks and learn new skills. Furthermore, to keep my website simple, I focused solely on the front-end of development with no back-end.
Generally, websites are developed using a combination of HTML, CSS, and JavaScript. To create this project, I enrolled in the Foundations course at The Odin Project (TOP), a course that allowed me to develop fundamental skills in these languages.
One of the main points that TOP hammers in to new students is to avoid generative AI usage, a point that I agree with for many reasons. Primarily, I wanted to fully learn web development instead of simply vibe coding without learning. Without AI to do the design, I would be required to engage with documentation, research modern development methods, and make many mistakes. I only used AI for particularly difficult debugging and research when appropriate, allowing me to focus on learning and developing the fundamental skills to improve my hobby project.
Front-End Development Challenges
Many times, I have found that I would have to make concessions when designing my website, whether for practical, aesthetic, or other reasons. For example, when creating a list of experiences, I found I was unable to leverage Node.js, a common back-end runtime environment that would simplify data storage and processing, since GitHub hosting only permits static webpages. To resolve this issue, I used large arrays to hold the necessary info. so no back-end would be required as an inefficient band-aid solution.
